OUR PROGRAMME FRAMEWORK

Skills for everyday digital life.

A practical framework for developing foundational skills, using online tools, creating useful content and protecting personal information.

01

FOUNDATIONS

Learn

Develop the basics that make digital tools easier to understand and use.

  • Understanding common devices and their functions
  • Using keyboards, touchscreens and basic settings
  • Managing files and folders
  • Creating and formatting simple documents
  • Understanding common digital terms and workflows
02

EVERYDAY TOOLS

Navigate

Use common online tools to communicate, organise information and collaborate.

  • Using email and managing messages
  • Cloud storage and file sharing
  • Finding and evaluating online information
  • Joining and participating in digital platforms
  • Basic digital collaboration practices
03

PRODUCTIVITY & EXPRESSION

Create

Turn digital skills into useful outputs for school, work and community life.

  • Preparing documents and presentations
  • Creating clear, useful digital content
  • Organising information for a task or audience
  • Using digital tools to support learning and work
04

ONLINE SAFETY

Protect

Recognise common risks and make more informed decisions online.

  • Recognising suspicious messages, links and scams
  • Creating and protecting stronger passwords
  • Using two-factor authentication where available
  • Understanding personal information and privacy
  • Safer online communication and account practices

LEARNING METHOD

Practice should lead to capability.

01Assess — identify learners' starting points and needs.

02Practise — use guided, hands-on activities.

03Apply — complete realistic tasks with less support.

04Measure — use practical checks to observe progress.

PRACTICAL INDICATORS

What progress may look like.

  • Create and format a document
  • Use email and cloud collaboration tools
  • Prepare a basic presentation
  • Identify common phishing and scam signals
  • Use safer password practices
  • Troubleshoot simple digital problems

These are intended learning indicators. They are not presented as results already achieved across a completed training programme.
